🎬 任务二 & 任务三 · creative / zoom / keyboard / 动态增删（含解释）

任务二 · creative 自定义变换● 自动播放运行中

原理：creativeEffect 的 prev/next 描述"前一张/后一张"的离场进场姿态。translate 的百分号相对 slide 自身尺寸（X 相对宽、Y 相对高，Z 只能用 px）——['-130%', 0, -220] 表示推到自己 1.3 倍宽的左边并后退 220px；rotate 三位 = 绕 X/Y/Z 轴的角度，Z 轴即屏幕内倾斜 20°；opacity: 0.4 让上一张渐隐。参数完全自定，观感如电影选片墙。

任务三 · zoom 双击缩放 ● 双击缩放

原理：图片必须包在 swiper-zoom-container 里，Swiper 才接管缩放——zoom.maxRatio: 3 上限 3 倍，toggle: true 双击切换放大/还原，放大后可拖动平移。keyboard.enabled 开启方向键翻页；onlyInViewport: true 让轮播只在滚进视口时响应按键——Swiper 把键盘事件绑在 document 上，触发时先检查自身与视口的位置关系再切换，避免长页面多个轮播一起动。

290-manipulation · 动态增删展品（appendSlide / prependSlide）● fraction 分页器实时重算总数

原理：appendSlide(HTML字符串) / prependSlide(数组) 在运行时插拔 slide（本页从 5 件展品池轮转取材生成新节点）；slidesPerView: 1.5 + centeredSlides: true 做出三屏居中效果；分页器 type: 'fraction' 显示"当前 / 总数"，插拔后 Swiper 自动重算 slide 总数并刷新显示，无需手动 update。

💡 一句话结论：提示词漏掉一个行为词，AI 就会替你"合理默认"一个坑——需求必须翻译成 显式的参数名和取值（disableOnInteraction: false），并且要亲手拖动验证，不能只看代码"长得对"。本页四块演示台（cube 对照 / creative / zoom+keyboard / 动态增删）就是 swiper-task.html 全部效果的浓缩版，答辩时一页讲完三个任务。
